# Projeto Loja de Joias

Um projeto desenvolvido durante o curso do SENAI com o objetivo de praticar conceitos de desenvolvimento web, utilizando HTML, CSS e JavaScript na criação de uma página de vendas de joias.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Página inicial de apresentação
* Catálogo de joias
* Layout responsivo
* Estilização moderna
* Interações com JavaScript

## Objetivo do Projeto

Este projeto foi criado para fins educacionais, com foco na prática de estruturação de páginas, estilização e desenvolvimento de interfaces web.
